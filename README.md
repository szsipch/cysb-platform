# 商场装修承接查验与整改闭环平台（MVP）

基于《商场装修承接查验 Vibe Coding 总框架》落地实现的可运行 MVP。
**零外部依赖**：纯 Node.js（无需 npm install、无需数据库、无需联网）即可运行。

## 启动

```bash
node server.js
# 或
npm start
```

浏览器打开 http://localhost:3000

> 首次运行会自动写入演示数据（位于 `data/db.json`）。如需重置，删除 `data/` 目录后执行 `node src/seed.js`。

## 技术说明

- 前端：原生 JS SPA（移动优先、响应式、零 CDN 依赖、离线可用），SVG 手绘图表
- 后端：Node 内置 `http`，JSON 文件存储（`data/db.json`），统一 API 层
- 图片：base64 上传落盘到 `uploads/`，前端按 URL 引用
- 状态机：所有状态变更走 `src/statemachine.js` 的 `nextStatus`，禁止散落硬编码
- 指标层：`src/metrics.js` 统一计算，避免各页面重复逻辑
- 报告引擎：`src/reports.js` 模板化 HTML，可打印为 PDF
- 遵循框架开发规则（第53/54条）：状态机强制、审计日志、不写死枚举（统一于 `src/constants.js`）

## V1.6 修复与增强（本轮用户试运行反馈）

### 关键深层修复：鉴权方式（解决"报告/打印/导出无反应"）
- **根因**：原认证仅靠 `Authorization` Header。浏览器用 `window.open` 打开新标签、或直接导航导出/查看接口时**不携带 Header**，导致报告查看、Word 导出、问题 CSV/Word 导出全部返回 **401**（表现为"点了没反应"）。
- **修复**：改为 **Cookie 鉴权**。登录/任意已鉴权接口响应写入 `Set-Cookie`（HttpOnly, SameSite=Lax）；`getToken` 同时支持 Header 与 Cookie；敏感导出/查看接口补 `ensureCookie`。此后所有 `window.open` 导出、报告打印、下载均可正常鉴权。

### 其他修复与增强
- **报告中心**：生成按钮改为"生成后刷新列表 + 提示"，避免 `await` 后 `window.open` 被浏览器拦截；报告 HTML 新增「🖨 打印 / 另存为 PDF」按钮（打印时自动隐藏工具栏）。
- **图片上传预览**：重写上传组件，选择图片后**实时显示缩略图**，并可点击「×」删除（问题发现照片、整改前后、复查照片统一支持）。
- **平面图定位开箱即用**：选择楼层即可点选定位；**未上传图时显示可点击网格**作为兜底；种子数据已为 3F/1F 写入 SVG 示例平面图，并为多个示例问题预置坐标，进入「平面图」页即可见分布点。
- **人员 / 角色配置**：新增「系统设置 → 人员/角色」页，超级管理员可新建（用户名/姓名/角色/初始密码）、删除账号；服务端新增 `PATCH /api/users/:id`（改角色/密码）、`DELETE /api/users/:id`，并放宽用户列表为登录即可读。
- **指派修复**：驳回（REJECTED）状态的问题再次指派可正确流转到 `ASSIGNED`。

## V1.7 二维码手机可扫 / 仪表盘联动 / 多统计表（已交付）

### 二维码手机扫码（修复"无反应"）
- 根因：二维码原先编码 `location.origin`（即 `http://localhost:3000`），手机扫到的是**手机自身**的 3000 端口，自然打不开。
- 修复：服务端新增 `GET /api/network` 返回局域网 IP 与端口；前端启动时拉取并记为 `S.baseUrl`；所有二维码改用 `S.baseUrl` 生成，手机与电脑同一 Wi-Fi 即可直达。
- 免登录只读分享：每条问题自动带 `shareToken`，新增公开接口 `GET /api/share/issue/:token`；问题详情二维码改为 `…/?issue=ID&share=TOKEN`，手机扫码**无需登录**即可查看问题详情、照片与整改/复查记录（只读，无编辑）。错误 token 返回 404。

### 仪表盘 KPI 联动
- 仪表盘 8 个指标卡（问题总数 / 未关闭 / 已关闭 / 已超期 / 闭环率 / 重大高风险率 / 一次通过率 / 按时整改率）现已可点击，点击即下钻到「问题中心」并按对应条件过滤（如点"已超期"只看超期问题）。统计表面板内的指标卡同样可下钻。

### 多个可自由编辑的统计表
- 原仪表盘统计为固定写死，现升级为「统计表」独立模块（左侧导航）：
  - 支持**多个**统计表，可新建 / 编辑 / 删除 / 设为默认，顶部 Tab 切换；
  - 每个表可**自由配置**：过滤条件（专业 / 楼层 / 严重度 / 状态 / 仅超期）、显示哪些指标卡、显示哪些图表；
  - 后端 `GET/POST/PATCH/DELETE /api/projects/:pid/statboards`，`dashboard` 接口支持可选过滤供统计表复用；种子内置默认表「总体概览（默认）」。
- 运行：`node server.js`（默认 3000；如被占用会用 `PORT=3001` 等，二维码自动适配）。
